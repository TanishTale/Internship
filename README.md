# TaskMaster - Modern CRUD Dashboard

A fully functional, frontend-only Task Management Dashboard. This project demonstrates how to build a Complete CRUD (Create, Read, Update, Delete) application using pure HTML, CSS, and Vanilla JavaScript, without needing a backend server.

## 🚀 Features

* **Create Tasks:** Add new tasks with title and priority levels (Low, Medium, High).
* **Read & Search:** View all tasks in a responsive grid layout. Includes a real-time search bar to filter tasks instantly.
* **Update Tasks:** Mark tasks as completed or revert them to pending with a single click.
* **Delete Tasks:** Remove unwanted tasks from the list permanently.
* **Dynamic Dashboard Stats:** Automatically calculates and displays the total, pending, and completed tasks.
* **Data Persistence:** Uses browser `LocalStorage` to save tasks. Your data remains safe even if you refresh the page or close the browser.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and modern dashboard layout.
* **CSS3:** Custom variables, CSS Grid, Flexbox, and smooth hover animations.
* **Vanilla JavaScript:** DOM manipulation, event listeners, array filtering, and LocalStorage API.
* **Phosphor Icons:** Modern icon library for the UI.

## 💻 How to Run

1. Clone or download this repository to your local machine.
2. Open the project folder.
3. Double-click the `index.html` file to open it in your default web browser (Chrome, Firefox, Safari, Edge, etc.).
4. No local server, Node.js, or database installation is required!
